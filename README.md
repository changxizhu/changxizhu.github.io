# 🌐 Personal Website — Changxi Zhu

This repository hosts my **academic and research website**, built using the [**al-folio**](https://github.com/alshedivat/al-folio) Jekyll theme.  
It contains my research interests, publications, blog posts, and teaching materials.

> 🏠 **Live site:** [https://changxi.me](https://changxi.me)

---

## 🧭 Overview

The site is powered by **Jekyll** and **GitHub Pages**, based on the minimalist academic theme **al-folio**.  
It supports:
- Academic CV and publications list  
- Blog posts written in Markdown  
- Project pages and teaching materials  
- MathJax and syntax highlighting  
- Responsive design with Bootstrap + MDBootstrap
